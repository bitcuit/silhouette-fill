# 실루엣 채움

그림의 실루엣 모양대로 글자(또는 작은 이미지 타일)를 채워 PNG·JPG로 저장하는 웹 도구입니다. 설치나 빌드 없이 `index.html` 하나로 동작합니다.

## 쓰는 법

1. 그림을 끌어다 놓거나, 붙여넣거나(Ctrl+V), **그림 선택**으로 엽니다.
2. **글** 칸에 채울 글을 씁니다. 일부를 선택해서 크기(50~400%)·굵게·기울임·밑줄·색을 바꿀 수 있습니다.
   줄바꿈은 공백으로 처리해 그림이 중간에 끊기지 않게 채우고, 줄 끝에서는 글자 단위로 넘어갑니다.
   서식은 **선택 서식 지우기**(선택한 부분만)와 **모든 서식 지우기**(글 전체)로 지울 수 있고, Ctrl+Z로 되돌릴 수 있습니다.
   글자 대신 **이미지**를 고르면 포토 모자이크를 만듭니다(아래 참고).
3. **배치** 탭에서 모양·크기·줄 간격을, **색** 탭에서 글자 색·배경을 정합니다.
4. 저장 크기와 형식(PNG/JPG)을 고르고 저장합니다. 기본은 원본과 같은 픽셀 크기의 PNG이고, 원본 파일에 DPI 정보가 있으면 그대로 옮겨 적습니다.

미리보기 아래 막대에서 확대/축소(Ctrl+휠도 가능)와 **투명 부분 흰색으로 보기**를 조절합니다. 흰색으로 보는 중에 투명 배경을 PNG로 저장하면, 배경을 투명하게 할지 흰색으로 할지 묻습니다. JPG는 투명을 담을 수 없어 흰색으로 채워집니다.

### 윤곽 기준

| 기준 | 쓰는 경우 |
|---|---|
| 투명도 | 배경이 투명한 PNG. 불투명한 부분이 모양이 됩니다. |
| 흰색 제외 | 흰 바탕 위의 그림. **그림 가장자리와 이어진 흰색(바탕)**을 빼고 나머지가 모양이 됩니다. 다른 색에 둘러싸인 안쪽 흰색(눈·흰 옷·하이라이트)은 모양에 들어갑니다. 안쪽 흰색까지 비우려면 **안쪽 흰색도 빼기**를 켜세요. 경계값이 클수록 흰색에 가까운 색까지 흰색으로 봅니다. |
| 전체 | 사진처럼 그림 전체를 글자로 채울 때 |

투명한 곳이 없는 그림을 열면 기본으로 **흰색 제외**가 선택됩니다. 흰 바탕이 없는 사진을 통째로 채우려면 **전체**를 고르세요.

### 글자 색

**그림 색**이면 글자마다 그 자리의 그림 색을 한 가지씩 가져와 칠합니다. 글자 하나하나 색이 달라서, 멀리서 보면 글자들이 모여 원본 그림처럼 보입니다(텍스트 포트레이트).

**한 색**이면 고른 기준 색의 색상은 그대로 두고 명도만 그 자리 밝기에 따라 달라집니다. 색 단순화 슬라이더로 명도 단계 수(2~16단계)를 정할 수 있습니다.

**두 색**이면 그 자리가 어두운지 밝은지에 따라 두 가지 색 중 하나로 칠합니다. 기본은 검정(#000000)·흰색(#FFFFFF)이고 둘 다 바꿀 수 있으며, **나누는 밝기**는 그림을 열 때 자동으로 잡힙니다.

이모지도 다른 글자처럼 한 가지 색으로 칠해집니다. (Windows에는 국기 이모지 글꼴이 없어 🇰🇷가 'KR'로 보입니다.)

그림처럼 보이게 하려면: **글 길이에 맞춰 그림 꽉 채우기**를 끄고 **기본 글자 크기**를 작게(8~12), **반복**을 켜고, **줄 간격**을 1.0 가까이, **획 두께**를 올리세요. 배경을 검정 단색으로 하면 색이 더 또렷합니다.

### 색 단순화

글자 색이 그림에서 올 때, 슬라이더로 그림의 대표색 2~16가지만 쓰도록 줄일 수 있습니다. 오른쪽 끝은 원본 색 그대로입니다.

### 크기 조절

- **글 길이에 맞춰 그림 꽉 채우기**: 쓴 글이 그림 전체를 딱 한 번 채우도록 글자 크기를 자동으로 정합니다. 부분적으로 키운 글자의 비율은 그대로 유지됩니다.
- 끄면 **기본 글자 크기**를 직접 정하고, 글이 모자랄 때 반복할지 고를 수 있습니다. 반복을 끈 상태에서 글이 모자라면 아래 상태 줄에 **몇 자를 더 쓰면 꽉 차는지** 알려 줍니다.
- **가장자리는 글자를 줄여서 채우기**(기본 꺼짐): 제 크기로는 윤곽에 걸리는 가장자리·끝부분에 같은 글자를 80%→40%까지 줄여 넣습니다. 가장자리가 더 차는 대신 작은 글자가 섞여 보입니다.
- 짧은 글로 꽉 채우기를 하면 글자가 커져서, 둥근 가장자리나 뾰족한 끝에는 큰 글자가 들어가지 못해 빈 곳이 남습니다. 모양을 촘촘히 채우려면 글자 크기를 작게 하고 **반복**을 켜세요.
- 슬라이더 옆 숫자 칸에 값을 직접 넣거나 화살표로 한 칸씩 조절할 수 있습니다.

### 글자 배치

일러스트레이터의 '영역 문자'처럼 동작합니다. 글자 하나하나가 획 두께까지 포함해 윤곽 안에 완전히 들어가는 자리에만 놓이고, 윤곽에 걸려 잘리는 글자는 없습니다. 글은 모양이 시작되는 맨 위 줄부터 왼쪽→오른쪽으로 흐르고, 한 줄이 모양의 빈 곳으로 갈라지면 같은 줄의 다음 구간으로 이어집니다.

줄 끝에 남는 자리(한 글자 폭보다 작음)는 글자 사이에 고르게 나눠서, 줄마다 윤곽 양 끝에 닿게 합니다. 글의 마지막 줄은 그대로 둡니다. **글 길이에 맞춰 그림 꽉 채우기**를 켜면 크기를 정한 뒤 자간도 살짝 넓혀, 글이 모양의 끝까지 이어지게 합니다.

### 긴 글

글이 길면 꽉 채우기가 글자를 아주 작게 만듭니다. 저장했을 때 글자가 9px보다 작아지면 뭉개져 보이므로, 상태 줄에 **저장 크기를 몇 배로 키우면 되는지** 알려 줍니다(저장 크기는 8배까지). 가장 작은 글자로도 다 들어가지 않으면 글을 줄이거나 더 큰 그림을 쓰라고 알려 줍니다.

## 포토 모자이크

**내용** 탭의 **채울 것**을 **이미지**로 바꾸면 글자 대신 작은 이미지(타일)로 그림을 채웁니다.

1. **이미지 추가**(또는 타일 칸에 끌어다 놓기)로 타일로 쓸 사진을 여러 장 넣습니다. 가운데를 정사각형으로 잘라 씁니다.
2. 모양 안을 정사각형 칸으로 나누고, 칸마다 **그 칸의 색을 가장 많이 가진 사진**을 고릅니다(평균색으로 고르면 반은 빨강·반은 초록인 사진이 갈색 칸에 뽑히는 식으로 어긋나서). 같은 사진이 바로 옆·위에 붙지 않게 조금 피합니다.
3. **색 보정 강도**만큼 사진의 색을 그 칸의 색 쪽으로 옮깁니다. 0%는 사진 색 그대로, 100%는 사진의 색 있는 부분이 칸의 색이 됩니다. 사진 속 무늬는 그대로 남고, **흰색에 가까운 부분(밝고 채도 낮은 곳)은 색을 입히지 않아** 흰 바탕·하이라이트가 흰색으로 남습니다.

**배치** 탭에서 **타일 크기**(원본 그림 px 기준)와 **타일 간격**을 정합니다. **사진 골고루 쓰기**(기본 30%)를 올리면 평균보다 많이 쓴 사진은 덜 뽑혀서 여러 사진이 고르게 섞입니다. 0%면 색이 가장 잘 맞는 사진만 고릅니다. 글자와 같은 규칙으로 칸 전체가 윤곽 안에 드는 곳에만 타일을 놓습니다. **색** 탭의 그림 색·한 색·두 색과 색 단순화도 그대로 적용됩니다.

## 글꼴 추가

화면의 **글꼴** 아래 칸에 웹폰트 CSS 주소(또는 .woff2/.ttf 파일 주소)를 넣고 **추가**를 누르면 바로 쓸 수 있습니다. 이렇게 추가한 글꼴은 그 브라우저에만 기억됩니다.

모든 방문자에게 기본으로 보이게 하려면 [`fonts.js`](fonts.js)에 항목을 추가하세요.

```js
{ name: '고운 바탕', family: 'Gowun Batang', css: 'https://fonts.googleapis.com/css2?family=Gowun+Batang:wght@400;700&display=swap' },
```

- 웹폰트 CSS 주소는 `css`에, 글꼴 파일을 저장소에 직접 넣을 때는 `file: 'fonts/파일이름.woff2'`로 적습니다.
- `family`는 웹폰트 CSS 안의 `font-family` 이름과 똑같아야 합니다.
- 맨 위 항목이 기본 글꼴입니다.

## GitHub Pages로 올리기

저장소를 GitHub에 올린 뒤 **Settings → Pages → Branch: `main` / `(root)`** 로 지정하면 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
